## معرفی

IVA یک پلتفرم حسابداری شخصی کامل است که فقط با HTML، CSS و JavaScript خالص ساخته شده است. هیچ فریم‌ورک، Build Step یا وابستگی خارجی ندارد. داده‌ها روی دستگاه کاربر ذخیره می‌شوند و برای اجرای برنامه فقط یک مرورگر مدرن نیاز است.

نسخه ۲ بازنویسی کامل تجربه IVA است: موتور نمودار SVG اختصاصی، تقویم شمسی واقعی، بودجه‌بندی و اهداف محاسبه‌شده از داده واقعی، حذف/ویرایش کامل با قابلیت برگردان (Undo)، رابط کاملاً دوزبانه و طراحی بانکی با حالت روز و شب.

## قابلیت‌ها

### 📊 داشبورد و تحلیل
- دارایی خالص، درآمد، هزینه و پس‌انداز با **داده واقعی** و انیمیشن شمارنده
- نمودار جریان نقدی ۶ ماهه، دونات دسته‌ها، روند خالص و اسپارک‌لاین — همه محاسبه‌شده از تراکنش‌ها
- «سلامت مالی» با نمره واقعی (پس‌انداز + بودجه + بدهی)
- تحلیل‌های هوشمند خودکار: هشدار بودجه، نرخ پس‌انداز، پیش‌بینی رسیدن به اهداف

### 💳 مدیریت مالی
- ثبت/ویرایش/حذف کامل تراکنش، حساب، بودجه، هدف و بدهی با **Undo**
- انتخاب دسته، حساب، نوع، تاریخ و یادداشت برای هر تراکنش
- موجودی حساب‌ها به‌صورت خودکار با تراکنش‌ها همگام می‌شود
- بودجه‌بندی دسته‌ای با درصد مصرف و هشدار عبور از سقف
- اهداف مالی با حلقه پیشرفت، افزودن پس‌انداز و تخمین زمان رسیدن
- بدهی/طلب با سررسید شمسی، شمارش روز مانده و وضعیت تسویه

### 🔍 جستجو و گزارش
- جستجوی زنده + فیلتر نوع، دسته، حساب، ماه و مرتب‌سازی
- گزارش‌های ۳/۶/۱۲ ماهه با نمودار خطی، میله‌ای، دونات و جدول دسته‌ها
- خروجی CSV استاندارد (با Quoting صحیح) و پشتیبان JSON + بازیابی از فایل

### 🌍 رابط کاربری
- فارسی/انگلیسی کامل (هیچ متن جامانده‌ای نیست) با RTL/LTR واقعی
- تقویم شمسی با `Intl` مرورگر — بدون هیچ کتابخانه
- حالت روشن/تاریک/سیستمی با ذخیره انتخاب
- فونت متغیر وزیرمتن (داخل پروژه، آفلاین)
- طراحی واکنش‌گرا: دسکتاپ، تبلت، موبایل (نوار ناوبری پایین + FAB + Bottom Sheet)
- دسترس‌پذیری: ARIA، Focus Trap در مودال‌ها، Esc، میان‌برهای صفحه‌کلید (N / / / T)
- نصب PWA با آیکون‌های any + maskable و اجرای کامل آفلاین

## اجرای سریع

هیچ نصب یا دستور خاصی لازم نیست:

1. پروژه را دانلود یا Clone کنید.
2. فایل `index.html` را در مرورگر باز کنید (برای PWA و فونت، با یک سرور محلی مثل Live Server اجرا کنید).

```bash
npx serve .        # یا
python3 -m http.server 8080
```

```text
│   ├── store.js       # وضعیت، اعتبارسنجی، مهاجرت v1→v2، داده نمونه
│   ├── charts.js      # موتور نمودار SVG (میله‌ای، خطی، دونات، حلقه، اسپارک)
│   └── app.js         # روتر، صفحات، فرم‌ها، اکشن‌ها، Undo، میان‌برها
├── index.html
├── style.css          # سیستم طراحی کامل دو-تمه
├── site.webmanifest
├── sw.js              # Service Worker (network-first + SWR)
└── README.md, CHANGELOG.md, ...
```
